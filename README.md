# ⚽ FOOTBALL HUB

**Everything Football. In One Place.**

FOOTBALL HUB is a modern football platform designed to bring live scores, fixtures, results, competitions, teams, players, standings, statistics and football news together in one place.

## 🌍 Features

* 🔴 Live football scores
* 📅 Today's matches and upcoming fixtures
* 🏆 Football leagues and competitions
* 📊 Standings and league tables
* ⚽ Teams and clubs
* 👤 Players and statistics
* 📰 Football news
* 🌎 International football
* 📱 Mobile-friendly design
* 🔄 Real-time football data

## 🏆 Competitions

The platform is designed to cover major football competitions, including:

* Premier League
* La Liga
* Serie A
* Bundesliga
* Ligue 1
* UEFA Champions League
* UEFA Europa League
* UEFA Conference League
* FIFA World Cup
* International competitions
* Other leagues and cups from around the world

## 🔌 Football Data

FOOTBALL HUB uses **API-Football** to retrieve football data such as fixtures, live matches, competitions, teams, players and standings.

The API connection is handled securely through a Vercel serverless endpoint. The API key is stored as the `API_FOOTBALL_KEY` environment variable and is not exposed in the frontend.
